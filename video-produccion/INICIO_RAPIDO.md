## 📝 Paso a Paso Ultra-Rápido

### 1️⃣ Slides en Canva (2 horas)

**Acción inmediata:**
1. Ve a https://www.canva.com/
2. Crea presentación 1920x1080
3. Usa estos colores:
   - Azul principal: `#2563EB`
   - Verde éxito: `#10B981`
   - Gris texto: `#1E293B`
   - Fondo: `#F8FAFC`

**14 slides que necesitas:**
```
01 → PORTADA: "Directorio de Talentos" + tu nombre
02 → "60% sin referencias confiables"
03 → "Millones de talentos invisibles"
04 → "Plataformas cobran 20-30%"
05 → "¿A quién llamas cuando necesitas ayuda?"
06 → "Directorio de Talentos - La Solución"
07 → "Búsqueda • Calificaciones • Contacto Directo"
08 → "HTML + CSS + JavaScript + Supabase"
09 → "Veamos cómo funciona..."
10 → "Nota: Demo en vivo (2 minutos)"
14 → "0% comisión • Ahorro $50-100"
15 → "Conexión vecinal • Confianza comunitaria"
16 → "De 100 a 100,000 usuarios"
17 → "Contacto + GitHub"
```

**Exportar:**
- Descargar → PNG → Alta calidad
- Guardar en `video-produccion/slides/`
- Renombrar: 01-portada.png, 02-problema-estadistica.png, etc.

### 2️⃣ Grabar Audio (30 min)

**Herramienta:** Audacity (gratis)

**Script rápido (5 minutos):**
```
[0:00-0:15] PORTADA
"Directorio de Talentos: conectando comunidades, empoderando talentos."

[0:15-1:00] PROBLEMA
"Cuando necesitas un plomero, ¿a quién llamas? El 60% de las personas 
no tiene referencias confiables. Millones de talentos están ocultos en 
nuestros barrios. Y las plataformas existentes cobran hasta 30% de comisión."

[1:00-1:15] PREGUNTA
"¿Y si pudieras encontrar al mejor profesional de tu barrio en segundos, 
con calificaciones verificadas, sin intermediarios?"

[1:15-2:15] SOLUCIÓN
"Directorio de Talentos es la respuesta. Una plataforma web simple que 
conecta vecinos con habilidades. Búsqueda instantánea, calificaciones 
de la comunidad, contacto directo. Construido con tecnología simple pero 
poderosa: HTML, CSS, JavaScript y Supabase."

[2:15-2:18] TRANSICIÓN
"Déjame mostrarte cómo funciona."

[2:18-4:18] DEMO (silencio - solo video)

[4:18-4:53] IMPACTO
"El impacto es real: cero comisiones versus 20-30% de otras plataformas. 
Ahorro promedio de 50 a 100 dólares por transacción. Pero más importante, 
fortalece la conexión vecinal y construye confianza comunitaria. 
Y es escalable: de 100 usuarios en un barrio a 100,000 en toda una ciudad."

[4:53-5:00] CIERRE
"Directorio de Talentos. Porque las mejores soluciones son las más simples. 
Código abierto en GitHub. ¡Gracias!"
```

**Proceso:**
1. Abre Audacity
2. Click en botón rojo (grabar)
3. Lee el script con energía
4. Exportar → MP3 → `narracion-completa.mp3`
5. Guardar en `video-produccion/audio/`

### 3️⃣ Grabar Demo (30 min)

**Herramienta:** OBS Studio o Windows Game Bar (Win+G)

**Qué grabar (2 minutos):**

```
[0:00-0:15] Página principal
→ Mostrar 6 perfiles
→ Scroll suave

[0:15-0:35] Búsqueda
→ Escribir "plomería"
→ Ver filtrado
→ Click en chip "Electricidad"

[0:35-1:05] Ver perfil
→ Abrir Juan Pérez
→ Mostrar 5 estrellas
→ Leer comentarios
→ Ver contacto

[1:05-1:50] Crear perfil
→ Click "Mi Perfil"
→ Llenar formulario:
  • Nombre: María Rodríguez
  • Habilidad: Diseño Gráfico
  • Descripción: "10 años de experiencia..."
  • Teléfono: 555-1234
  • Email: maria@email.com
  • Barrio: Miraflores
→ Guardar
→ Volver a inicio
→ Mostrar nuevo perfil

[1:50-2:00] Calificar
→ Abrir perfil
→ Dar 5 estrellas
→ Comentario: "Excelente servicio"
→ Guardar
```

**Preparación:**
1. Abre `directorio-talentos/index.html`
2. Zoom navegador: Ctrl + + (2-3 veces)
3. Cierra otras pestañas
4. Practica 1 vez

**Grabar:**
1. Inicia OBS o Win+G
2. Graba pantalla completa
3. Sigue el guion
4. Guarda como `demo-app.mp4` en `video-produccion/grabaciones/`

### 4️⃣ Editar Video (3 horas)

**Herramienta:** DaVinci Resolve (gratis) o Shotcut

**Proceso rápido:**

1. **Nuevo proyecto** (5 min)
   - Resolución: 1920x1080
   - FPS: 30

2. **Importar archivos** (5 min)
   - 13 slides PNG
   - Audio narración
   - Video demo

3. **Timeline** (2 horas)
   ```
   Pista 1 (Video): Slides + Demo
   Pista 2 (Audio): Narración
   ```
   
   **Orden:**
   - 0:00 → Slide 01 (15s)
   - 0:15 → Slide 02 (15s)
   - 0:30 → Slide 03 (15s)
   - 0:45 → Slide 04 (15s)
   - 1:00 → Slide 05 (15s)
   - 1:15 → Slide 06 (20s)
   - 1:35 → Slide 07 (20s)
   - 1:55 → Slide 08 (20s)
   - 2:15 → Slide 09 (3s)
   - 2:18 → Slide 10 (0s - aparece mientras demo)
   - 2:18 → DEMO VIDEO (2 min)
   - 4:18 → Slide 14 (15s)
   - 4:33 → Slide 15 (10s)
   - 4:43 → Slide 16 (10s)
   - 4:53 → Slide 17 (7s)

4. **Transiciones** (15 min)
   - Entre slides: Fade 0.3s
   - Demo entrada/salida: Fade 0.5s

5. **Revisar** (15 min)
   - Ver completo
   - Ajustar timing
   - Verificar audio

6. **Exportar** (20 min)
   - Formato: MP4
   - H.264, 1920x1080, 30fps
   - Bitrate: 8 Mbps
   - Nombre: `directorio-talentos-presentacion-final.mp4`
   - Guardar en `video-produccion/proyecto-final/`

## 🆘 Problemas Rápidos

**No tengo tiempo para todo:**
→ Usa presentación web interactiva (`video-slides/presentacion.html`)
→ Graba pantalla mientras navegas slides
→ Narra en vivo

**Audio con ruido:**
→ Audacity → Efecto → Reducción de ruido

**Video muy pesado:**
→ Reduce bitrate a 6 Mbps
→ O usa Handbrake para comprimir

**No sé usar el editor:**
→ YouTube: "Tutorial [nombre editor] para principiantes"
→ O usa CapCut (más simple)
