# 🚀 Publicar Presentación BOB-A-THON - Guía Rápida

## ⚡ OPCIÓN 1: Servidor Local (MÁS RÁPIDO - 30 segundos)

### Para compartir en tu red local o proyectar:

1. **Haz doble clic en**: `iniciar-servidor.bat`
2. Se abrirá una ventana con las URLs
3. **Comparte la URL** que aparece con tu IP local

**Ejemplo de URL:**
```
http://192.168.1.100:8000/presentacion.html
```

✅ **Ventajas:**
- Listo en 30 segundos
- No necesitas internet
- Funciona en tu red local
- Perfecto para presentar en el mismo lugar

❌ **Limitación:**
- Solo funciona en tu red local
- Debes mantener tu computadora encendida

---

## 🌐 OPCIÓN 2: GitHub Pages (Permanente)

### Paso 1: Crear repositorio en GitHub
1. Ve a: https://github.com/new
2. **Repository name**: `BOB-A-THON`
3. Marca como **Public**
4. Click en **Create repository**

### Paso 2: Subir archivos
Abre PowerShell en esta carpeta y ejecuta:

```powershell
git push -u origin master
```

### Paso 3: Activar GitHub Pages
1. En tu repositorio → **Settings** → **Pages**
2. Source: **master** branch
3. **Save**

### Paso 4: Tu URL será:
```
https://elitaniafm1993-maker.github.io/BOB-A-THON/presentacion.html
```

✅ **Ventajas:**
- URL permanente
- Accesible desde cualquier lugar
- Gratis
- Profesional

## 🎯 OPCIÓN 3: Netlify Drop (Sin Git - 2 minutos)

### Pasos:
1. Ve a: https://app.netlify.com/drop
2. **Arrastra toda la carpeta BOB-A-THON**
3. ¡Listo! Te da una URL instantánea

**URL ejemplo:**
```
https://bobathon-presentacion.netlify.app/presentacion.html
```

✅ **Ventajas:**
- Súper rápido (2 minutos)
- No necesitas Git
- URL personalizable
- HTTPS automático

## 🎬 Para Presentar:

Una vez publicada, abre la URL y:
1. Presiona **F** para pantalla completa
2. Usa **flechas ← →** para navegar
3. O usa los **botones** en la esquina inferior derecha

---

## 📱 Compartir URL

## 🆘 Ayuda Rápida

### Servidor local no inicia
- Verifica que Python esté instalado: `python --version`
- Instala Python desde: https://python.org

### GitHub Pages no funciona
- Espera 2-3 minutos después de activar
- Verifica que el repositorio sea público
- La URL debe terminar en `/presentacion.html`
