# 🚀 PLAN DE ACCIÓN: GRABA TU VIDEO HOY

## ⏰ TIEMPO TOTAL: 3 HORAS

---

## 📅 HORA 1: PREPARACIÓN (60 minutos)

### ✅ Paso 1: Crear Slides en Canva (40 minutos)

**Acción inmediata**:
1. Abre [www.canva.com](https://www.canva.com)
2. Crea cuenta gratuita (o inicia sesión)
3. Clic en "Crear diseño" → "Presentación" (16:9)

**Crear los 17 slides**:
- Abre el archivo `video-slides/TODOS_LOS_SLIDES.md`
- Copia el contenido de cada slide
- Usa los colores exactos especificados
- Font: Inter (disponible gratis en Canva)

**Atajos rápidos**:
- Duplica slides similares (ahorra tiempo)
- Guarda tu paleta de colores en "Mis colores"
- Usa Ctrl+D para duplicar elementos

**Descargar**:
- Clic en "Compartir" → "Descargar"
- Formato: PNG
- Calidad: Alta
- Descarga todas las páginas

**Resultado**: Carpeta con 17 imágenes PNG

---

### ✅ Paso 2: Preparar la Aplicación (10 minutos)

**Verificar que funciona**:
```bash
cd directorio-talentos
# Abrir index.html en navegador
```

**Checklist**:
- [ ] Se ven los 6 perfiles de ejemplo

**Tip**: Escribe estos datos en un notepad para copiar/pegar rápido

---

### ✅ Paso 3: Configurar Grabación (10 minutos)

**Opción A: Loom (Recomendado - MÁS FÁCIL)**

1. Ve a [www.loom.com](https://www.loom.com)
2. Descarga la app (Windows/Mac)
3. Instala y crea cuenta gratuita
4. Abre Loom
5. Selecciona "Screen + Camera" o solo "Screen"
6. Selecciona tu pantalla completa
7. Prueba grabando 10 segundos

**Opción B: OBS Studio (Gratis pero más complejo)**

1. Descarga de [obsproject.com](https://obsproject.com)
2. Instala
3. Configuración:
   - Sources → Display Capture
   - Settings → Output → Recording Quality: High
   - Settings → Audio → Selecciona tu micrófono
4. Prueba grabando 10 segundos

**Opción C: PowerPoint (Si tienes Office)**

1. Abre PowerPoint
2. Importa tus slides
3. Pestaña "Presentación con diapositivas"
4. "Grabar presentación con diapositivas"
5. Activa micrófono

---

## 📹 HORA 2: GRABACIÓN (60 minutos)

### ✅ Paso 4: Preparar el Entorno (5 minutos)

**Checklist pre-grabación**:
- [ ] Cerrar todas las apps innecesarias
- [ ] Desactivar notificaciones (Windows: Win+A → "No molestar")
- [ ] Cerrar Slack, WhatsApp, Email
- [ ] Poner teléfono en silencio
- [ ] Tener agua cerca
- [ ] Ir al baño 😊

**Configurar pantalla**:
- [ ] Navegador en pantalla completa (F11)
- [ ] Zoom del navegador: 125% (Ctrl + +)
- [ ] Ocultar barra de marcadores
- [ ] Limpiar escritorio (si se ve)

**Audio**:
- [ ] Micrófono probado
- [ ] Lugar silencioso
- [ ] Cerrar ventanas (ruido externo)
- [ ] Avisar a familia/compañeros

---

### ✅ Paso 5: Practicar (15 minutos)

**Práctica 1: Solo narración (5 min)**
- Lee el script en voz alta
- Cronometra el tiempo
- Ajusta velocidad si es necesario

**Práctica 2: Solo demo (5 min)**
- Navega la aplicación sin grabar
- Memoriza el flujo
- Practica escribir los datos

**Práctica 3: Completa (5 min)**
- Narración + acciones juntas
- Sin grabar aún
- Identifica partes difíciles

---

### ✅ Paso 6: GRABAR (40 minutos)

**Estrategia recomendada: Grabar por secciones**

#### Sección 1: Slides Introductorios (10 min)
```
Grabar: Slides 1-8 (Portada hasta Tecnología)
Duración: ~2 minutos
```

**Cómo hacerlo**:
1. Abre tus slides en pantalla completa
2. Inicia grabación
3. Narra siguiendo el script
4. Cambia slides manualmente (clic o flecha)
5. Detén grabación
6. Guarda como: `parte1-intro.mp4`

---

#### Sección 2: Demo de la Aplicación (20 min)
```
Grabar: Aplicación funcionando
Duración: ~2 minutos
```

**Cómo hacerlo**:
1. Abre la aplicación en navegador
2. Inicia grabación
3. Sigue el script de demo:
   - Buscar "plomería"
   - Abrir perfil de Juan
   - Ir a "Mi Perfil"
   - Crear perfil de María
   - Calificar
4. Detén grabación
5. Guarda como: `parte2-demo.mp4`

**Tips**:
- Movimientos de mouse LENTOS
- Pausar 2 segundos después de cada acción
- Si te equivocas, detén y reinicia

---

#### Sección 3: Slides Finales (10 min)
```
Grabar: Slides 14-17 (Impacto y Cierre)
Duración: ~1 minuto
```

**Cómo hacerlo**:
1. Abre slides finales
2. Inicia grabación
3. Narra impacto y cierre
4. Detén grabación
5. Guarda como: `parte3-cierre.mp4`

---

### 🎯 ALTERNATIVA: Grabar Todo de Una Vez (40 min)

Si prefieres grabar todo junto:

**Preparación**:
1. Abre slides en una ventana
2. Abre aplicación en otra ventana
3. Ten el script visible (pantalla secundaria o impreso)

**Grabación**:
1. Inicia grabación de pantalla completa
2. Empieza con slides
3. Cambia a aplicación para demo
4. Vuelve a slides para cierre
5. Detén grabación

**Ventaja**: Más fluido, menos edición
**Desventaja**: Si te equivocas, reiniciar todo

## ✂️ HORA 3: EDICIÓN Y PUBLICACIÓN (60 minutos)

### ✅ Paso 7: Editar Video (40 minutos)

**Si grabaste por secciones**:

**Opción A: Loom (Automático)**
- Loom une todo automáticamente
- Solo necesitas recortar inicio/final
- Agregar música de fondo (opcional)

**Opción B: Editor Simple**

**Windows**:
1. Abre "Video Editor" (viene con Windows 10/11)
2. Nuevo proyecto → "Video de presentación"
3. Agregar videos: parte1, parte2, parte3
4. Agregar música de fondo (opcional):
   - YouTube Audio Library
   - Volumen: 10-20%
5. Exportar → Calidad alta

**Mac**:
1. Abre iMovie
2. Nuevo proyecto
3. Importar las 3 partes
4. Agregar música (opcional)
5. Exportar → 1080p

## 🆘 SOLUCIÓN RÁPIDA DE PROBLEMAS

### "No tengo tiempo para 3 horas"

**Versión Express (1 hora)**:
1. Salta crear slides → Usa solo la aplicación
2. Graba solo demo (2 minutos)
3. Agrega intro y outro con texto en editor
4. Total: 3 minutos de video

### "Mi audio suena mal"

**Solución rápida**:
1. Usa audífonos con micrófono
2. Graba en un closet (absorbe eco)
3. Habla más cerca del micrófono
4. Usa Audacity para limpiar (gratis)

### "La demo no salió bien"

**Solución**:
1. Graba solo la demo de nuevo
2. Reemplaza esa sección
3. O graba sin audio y narra después

### "El video es muy largo"

**Solución**:
1. Habla más rápido (pero claro)
2. Reduce pausas
3. Acorta la demo (solo búsqueda y crear perfil)

### "No sé editar video"

**Solución**:
1. Usa Loom (no requiere edición)
2. O graba todo perfecto en una toma
3. O usa PowerPoint con grabación
