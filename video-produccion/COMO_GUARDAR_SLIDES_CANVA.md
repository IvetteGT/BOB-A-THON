# 📥 Cómo Guardar Slides desde Canva - Guía Paso a Paso

## 🎨 Método 1: Exportar desde Canva (Recomendado)

### Paso 1: Termina tu Presentación en Canva
1. Abre tu presentación en Canva
2. Verifica que tengas los 14 slides completos
3. Revisa que todo se vea bien

### Paso 2: Descargar
1. **Click en el botón "Compartir"** (esquina superior derecha)
2. **Selecciona "Descargar"**
3. Verás opciones de descarga

### Paso 3: Configurar Descarga
```
┌─────────────────────────────────────┐
│  Tipo de archivo: PNG ✓             │  ← Selecciona PNG
│  ○ JPG                              │
│  ● PNG                              │  ← IMPORTANTE: PNG
│  ○ PDF                              │
│  ○ Video                            │
│                                     │
│  Calidad: Alta ✓                    │  ← Selecciona Alta
│  ○ Estándar                         │
│  ● Alta                             │  ← IMPORTANTE: Alta
│                                     │
│  Páginas: Todas ✓                   │  ← Todas las páginas
│  ● Todas las páginas (1-14)         │
│  ○ Páginas personalizadas           │
│                                     │
│  [    Descargar    ]                │  ← Click aquí
└─────────────────────────────────────┘
```

### Paso 4: Esperar Descarga
- Canva procesará tu presentación (10-30 segundos)
- Se descargará un archivo ZIP automáticamente
- Nombre típico: `Directorio-de-Talentos.zip` o similar

### Paso 5: Descomprimir ZIP
1. Ve a tu carpeta de **Descargas**
2. Busca el archivo `.zip` recién descargado
3. **Click derecho** en el archivo
4. Selecciona **"Extraer todo..."** o **"Extract here"**
5. Se creará una carpeta con todos los PNG

### Paso 6: Mover a Carpeta Correcta
1. Abre la carpeta extraída
2. Verás archivos como:
   ```
   Directorio-de-Talentos_1.png
   Directorio-de-Talentos_2.png
   Directorio-de-Talentos_3.png
   ...
   Directorio-de-Talentos_14.png
   ```

3. **Selecciona TODOS los archivos PNG** (Ctrl+A)
4. **Copia** (Ctrl+C)
5. Navega a: `C:\Users\IvetteGonzalezTovar\Desktop\BOB-A-THON\video-produccion\slides\`
6. **Pega** (Ctrl+V)

### Paso 7: Renombrar Archivos (IMPORTANTE)
Los archivos deben tener estos nombres exactos:

```
01-portada.png
02-problema-estadistica.png
03-talentos-ocultos.png
04-intermediarios.png
05-pregunta.png
06-concepto.png
07-caracteristicas.png
08-tecnologia.png
09-transicion-demo.png
10-nota-demo.png
14-impacto-economico.png
15-impacto-social.png
16-escalabilidad.png
17-cierre.png
```

**Cómo renombrar:**
1. Click derecho en el primer archivo
2. Selecciona "Cambiar nombre" o presiona F2
3. Escribe: `01-portada.png`
4. Presiona Enter
5. Repite para cada archivo

## 🎨 Método 2: Descargar Página por Página

Si prefieres descargar uno por uno:

### Para cada slide:
1. Abre el slide en Canva
2. Click en "Compartir" → "Descargar"
3. Tipo: PNG
4. Calidad: Alta
5. Páginas: **Solo página actual**
6. Descargar
7. Renombrar inmediatamente con el nombre correcto
8. Mover a `video-produccion/slides/`

## 🆘 Problemas Comunes

### "No encuentro el botón Descargar"
✅ **Solución**: 
- Busca el botón "Compartir" (arriba a la derecha)
- Dentro del menú, está "Descargar"

### "Solo descarga 1 página"
✅ **Solución**:
- En opciones de descarga, selecciona "Todas las páginas"
- No "Página actual"

### "El archivo es JPG, no PNG"
✅ **Solución**:
- En tipo de archivo, cambia de JPG a PNG
- PNG tiene mejor calidad para slides

### "Los archivos son muy pequeños"
✅ **Solución**:
- Asegúrate de seleccionar calidad "Alta"
- No "Estándar"

### "No puedo descomprimir el ZIP"
✅ **Solución**:
- Windows: Click derecho → "Extraer todo"
- O usa 7-Zip (gratis): https://www.7-zip.org/

### "Los nombres son muy largos"
✅ **Solución**:
- Usa nombres cortos como indiqué arriba
- Facilita la edición después

2. ✅ Verifica que no haya elementos cortados
3. ✅ Comprueba que el texto sea legible
4. ✅ Haz backup en otra carpeta o USB

## 🎬 Alternativa: Captura de Pantalla

Si tienes problemas con Canva:

### Método de captura:
1. Abre slide en Canva en modo presentación
2. Presiona **F11** (pantalla completa)
3. Presiona **Win + Shift + S** (Windows)
4. Selecciona área completa del slide
5. Pega en Paint: **Ctrl + V**
6. Guardar como PNG
7. Repetir para cada slide

**Nota**: Este método es menos ideal pero funciona en emergencias.
